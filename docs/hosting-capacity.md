# برآورد منابع هاست (Node.js اشتراکی) — همراه استخدام

## اندازه‌های واقعی اندازه‌گیری‌شده (Build تولیدی)

| مورد | اندازه |
| --- | --- |
| کد منبع `src` | 1.6 MB |
| مایگریشن‌ها `db` | 147 KB |
| فایل‌های استاتیک `public` | 25 KB |
| خروجی build `dist/client` | 2.5 MB (201 فایل asset) |
| خروجی build `dist/server` | 5.8 MB |
| کل `dist` | 8.3 MB |
| `node_modules` توسعه | 343 MB |

نکته کلیدی: با preset `node-server` خروجی Nitro همه وابستگی‌ها را باندل می‌کند، بنابراین روی هاست نیازی به آپلود `node_modules` (343 MB) نیست؛ فقط `dist` منتقل می‌شود.

## حداقل فضای دیسک روی هاست

| سناریو | فضای لازم |
| --- | --- |
| فقط `dist` (build روی سیستم خودتان) | ~10 MB |
| + لاگ و کش موقت | ~150 MB |
| اگر build روی خود هاست انجام شود (نیاز به node_modules) | ~600 MB |
| **پیشنهاد امن** | **1 GB** |

بار اصلی داده (کاربران، آزمون‌ها، پاسخ‌ها، فایل‌ها) روی Supabase است، نه دیسک هاست.

## جدول برآورد بر اساس تعداد کاربر

فرض‌ها: هر کاربر فعال ماهانه ~۳۰ درخواست SSR + ~۱۵۰ فراخوانی API، اوج مصرف ۱۰٪ کاربران در ساعت پیک، هر پردازه Node حدود ۱۲۰–۲۵۰ MB RAM.

| کاربر ثبت‌نامی | کاربر فعال روزانه | RAM پیشنهادی | CPU | فضای دیسک | پهنای باند ماهانه | دیتابیس Supabase | توضیح |
| --- | --- | --- | --- | --- | --- | --- | --- |
| تا ۵۰۰ | ~۵۰ | 512 MB | 1 vCPU (اشتراکی) | 1 GB | ~۵ GB | Free (500 MB) | هاست اشتراکی نودجی‌اس کافی است |
| ۵۰۰ – ۲٬۰۰۰ | ~۲۰۰ | 1 GB | 1 vCPU | 1 GB | ~۲۰ GB | Free/Pro | همچنان اشتراکی، یک پردازه |
| ۲٬۰۰۰ – ۱۰٬۰۰۰ | ~۸۰۰ | 2 GB | 2 vCPU | 2 GB | ~۸۰ GB | Pro (8 GB) | مرز خروج از اشتراکی؛ VPS توصیه می‌شود |
| ۱۰٬۰۰۰ – ۵۰٬۰۰۰ | ~۴٬۰۰۰ | 4 GB | 2–4 vCPU | 5 GB | ~۴۰۰ GB | Pro + | ۲ پردازه با pm2 cluster + CDN |
| بیش از ۵۰٬۰۰۰ | ۱۰٬۰۰۰+ | 8 GB+ | 4+ vCPU | 10 GB | 1 TB+ | Pro/Team | چند نمونه پشت لودبالانسر |

نکته آزمون همزمان: هر ۱۰۰ کاربری که هم‌زمان در حال دادن آزمون هستند تقریباً ۱۵۰–۲۰۰ MB رم اضافه و یک هسته CPU در اوج مصرف می‌کند.

## الزامات هاست

- Node.js نسخه ۲۰ یا بالاتر (۲۲ توصیه می‌شود)
- امکان اجرای پردازه دائمی (pm2/passenger) — هاست فقط PHP کار نمی‌کند
- امکان تعریف متغیرهای محیطی (`.env`)
- دسترسی خروجی HTTPS به Supabase، درگاه پرداخت و پنل پیامک
- گواهی SSL روی دامنه

## مراحل استقرار

```bash
# روی سیستم خودتان
NITRO_PRESET=node-server npm run build
# آپلود پوشه dist و فایل .env روی هاست
node dist/server/index.mjs   # یا: pm2 start dist/server/index.mjs --name hamrah
```

متغیرهای لازم در `.env`: `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `VITE_SUPABASE_*`, `APP_URL`, کلیدهای درگاه پرداخت و پنل پیامک.
